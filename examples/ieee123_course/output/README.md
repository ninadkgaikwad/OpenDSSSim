# Generated output directory

Each run creates a timestamp-free, user-selected **unique run ID** below this directory, e.g. `output/intro_001/`. The course refuses to overwrite a prior run.

Only this README and `.gitkeep` are versioned by default. Reference data is under `input/reference_results/`, clearly marked as **archived research evidence**, not generated by a newcomer.

Never use `output/` as a source of mandatory input data. The course should also work after its generated output folders are deleted.
