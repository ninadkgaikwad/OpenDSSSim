# B00I1 — Native-as-installed time-series pilot (first implementation)

**Status:** installed only after guarded checks; qualification requires native laptop evidence and independent review. This note does not authorize the final B00 freeze.

## Four primary IEEE-123 feeder variants

1. `ieee123_base`: native regulator actions, no native CapControl/InvControl; no PV.
2. `ieee123_pesgm2027`: same plus ten physically connected PV systems; no native inverter automation; no outside PV Q actions.
3. `ieee123_p2_mf01_simple`: MF01 PRE (faulted `Line.L45`, `Line.L77`, `Line.L93`, `Line.Sw7`), existing initial switch states; no restoration.
4. `ieee123_p2_mf02_exotic`: MF02 PRE (faulted `Line.L45`, `Line.L77`, `Line.L93`), existing initial switch states; no restoration.

`ieee123_p2_restoration` remains a historical candidate, not an approved B00 primary experiment. All five feeder folders are preserved without mutation. P2 variation uses the original ratified sources, not reconstructed post-restoration switching or invented new fault timing.

## Scientific execution contract

`NativeControlsBaseline` is an external controller client with no backend/Plant access. It checks the A05I6 detached context action layout and A04 action-space membership, returns a new `{}`, and never sets native controls. The experiment runner uses `OpenDSSSimulator(problem=..., exogenous_replay=...)`, one initial reset plus N calls to `env.step({})`, native solved snapshots, A03/A04 semantic bus-voltage observation, retained H1/H2 history, and `SolutionResult` control-iteration counts. P2 static faults are applied only by A04 `FaultSpec` and are verified by that existing runtime. The simulator source remains untouched.

The pilot produces synthetic demonstration CSVs (`load_multiplier_pu` shared across 91 loads, optional ten-PV `irradiance_kw_m2`), with named units, exact input hashes, UTC timestamps, replay provenance and true zero-load/zero-PV profile values. These are **not real field profiles** and not official P1/P2 comparison datasets. Full comparison campaigns require frozen shared input datasets, consistent initialization, and explicit missing-voltage/thermal treatment.

### Measured and deferred metrics

Recorded directly from the authorized runtime: convergence, solution iterations, `control_iterations`, feeder P/Q, raw bus/phase voltage extrema, nonzero-voltage extrema (not a verified energized topology), outside-0.95/1.05 nonzero count, zero-voltage phase count, sample UTC indices, A04 no-action audits, and replay source fingerprints.

H2 optional trusted **recorder** uses `env.history[-1]['full_state']` (already generated by A05) and A03 semantic IDs for transformer tap and capacitor-state values. Status `NOT_IMPLEMENTED_UNAVAILABLE` or `PARTIAL` remains explicit where native values cannot be read. It never gives the external controller additional state/privilege. In H1, the unavailable-history status is explicit.

**Known A05 capability gaps remain**: effective native `ControlMode`, RegControl `Enabled` runtime readbacks through A04, native control queue and per-event tap movements, and a feeder-level loss readout. A positive control-iteration count alone does not prove every RegControl operated. B00I1 pilot qualification must not be mislabeled full B00 science/telemetry freeze while gaps persist.

The IEEE-123 `Run_IEEE123Bus.DSS` script is not compiled; do not silently apply its `Set MaxControlIter=30` or delayed regulator settings. The actual master files are loaded, and user cannot externally command switch restoration in B00.
