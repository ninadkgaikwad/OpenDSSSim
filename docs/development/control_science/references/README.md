# Controller Literature Evidence

This directory stores source audits and bibliographic provenance for the six PESGM
controller baselines.

Primary anchors are audited from full text before equations or algorithms are frozen.

Each audit must distinguish:
- `SOURCE` — explicitly supported by the cited source;
- `ADAPTATION` — a deliberate change to make the three paradigms solve one common
  OpenDSSSim problem;
- `OPENDSSSIM-SOFTWARE` — framework/interface work, not controller algorithm novelty.

Exact DOI/link provenance must be retained.

`bibliography.bib` is intentionally a scaffold in C0A. Bibliographic entries should be
added only after metadata is checked against authoritative publication records.
