# P2 — Common Reconfiguration / Restoration Physical Problem

**Status:** C0A scaffold — NOT FROZEN

The first scientific decision in C1/C3 is to ensure that reference, optimization/MPC,
and RL controllers solve the same physical task.

The literature audit must determine whether the paper benchmark is:
- normal reconfiguration;
- post-fault restoration; or
- an explicitly unified restoration/reconfiguration problem.

Do not allow the three paradigms to silently solve different problems.
